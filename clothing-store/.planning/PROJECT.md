# Clothies 3D Apparel E-Commerce Platform

## Project Overview
A progressive 3D e-commerce storefront for "Clothies" (Offcut Atelier) featuring interactive CSS 3D garments, motion design inspired by MotionSites, complete catalog browsing, product quick-view modal, responsive cart slide-over, and Playwright verification.

## Technology Stack
- **Frontend Core**: Semantic HTML5, Modern CSS (3D Perspective transforms, CSS Variables, Glassmorphism, CSS Grid), Vanilla ES6+ JS
- **Typography**: UnifrakturMaguntia (Gothic Blackletter), Instrument Serif (Editorial Luxury Italic), Inter (Modern Body & UI)
- **Design Intelligence**: MotionSites AI design recipes (`clothing-rail`)
- **Testing & Verification**: Playwright MCP browser automation and unit verification
